# 氢天气用户协议

更新日期：2026 年 11 月 6 日。适用于 `com.sugar.weather` 当前版本。

## 1. 应用与服务

氢天气是一款以氢 OS 天气为视觉参考的独立 Android 天气项目，用于非商业学习与演示。当前提供城市搜索、实况与预报展示、本机城市管理及天气动画，不提供账号、付费订阅或自有云同步服务。

本项目与 OnePlus、Hydrogen OS 及原天气应用无隶属、授权或合作关系，相关名称与商标归其权利人所有。项目中的程序化动画和新绘制的 Logo 不代表任何厂商的官方素材。

## 2. 天气信息的使用

天气数据由 Open-Meteo 提供，可能受模型、观测时间、网格分辨率、网络或第三方服务状态影响。部分数据经过本应用的模型合并、取整和白天天气聚合，因此与其他应用或当地实测可能不同。

页面中的空气质量文字是当前 PM2.5 浓度的近似分档，不是完整中国 AQI；紫外线使用当天预报最大值。离线或刷新失败时会显示上一次缓存，请留意更新时间。

本应用没有气象灾害预警功能。出行、航行、登山、医疗、救灾或其他可能影响人身财产安全的决定，应结合当地气象部门发布的预报与预警，不能仅依据本应用。

## 4. 权限、本地数据与删除

定位权限可选，拒绝后可以手动搜索添加城市。查询天气需要联网，并将对应城市坐标发送给天气服务；城市搜索会发送搜索词。具体处理方式见本应用的隐私政策。

城市列表、排序和最近一次天气保存在本机。城市管理页支持删除手动城市及对应缓存；定位城市当前固定置顶，不支持单独删除。清除应用存储或卸载会删除设备上的应用私有副本，Android 系统备份与迁移可能按设备设置恢复符合规则的数据。

应用没有云端账号，无法代为恢复已清除的本机数据，也无法代为管理用户的系统备份。
