# 氢天气隐私政策

更新日期：2026 年 11 月 6 日。适用于 `com.sugar.weather` 当前版本。

## 1. 概述

氢天气没有注册账号、广告、行为分析或崩溃上报 SDK，没有项目自建服务器，不提供自有云同步。本政策说明应用实际处理的数据、第三方请求和本机删除方式。

天气查询和城市搜索需要网络；用户协议、隐私政策、使用帮助、版本日志和组件说明均随安装包提供，可以离线阅读。

## 2. 城市与天气数据

应用在私有 DataStore 中保存城市名称、经纬度、城市标识、定位标记、排序和添加时间，以及最近一次实况、逐时、逐日、空气质量和抓取时间。这些信息用于多城市展示、请求对应地点天气及离线缓存。

手动添加的城市坐标来自搜索结果或内置热门城市；定位城市的坐标来自获得授权后的系统位置服务。天气请求直接到达 Open-Meteo，不经过项目服务器。

## 3. 位置信息与可选权限

应用声明 `ACCESS_COARSE_LOCATION` 与 `ACCESS_FINE_LOCATION`，用于按首页逻辑尝试获取所在城市。系统权限由用户决定，可以拒绝或在 Android 设置中撤销；拒绝后仍可手动搜索、添加和查看城市天气。

定位使用 Android `LocationManager`，可读取最近的位置缓存或请求一次位置更新，成功、超时或任务取消后停止监听。不申请后台定位权限，不提供后台持续定位或轨迹记录。当前版本的大致位置成功率和已有定位城市的坐标更新仍有局限，详见使用帮助。

定位坐标用于天气查询，并交给系统 `Geocoder` 解析城市名称。Geocoder 可能连接设备或系统提供方的网络服务，其提供方与数据处理规则由设备系统决定。

关闭定位权限不会自动移除已保存的定位城市，也不会阻止对保存坐标查询天气；清除该本机位置记录需要通过系统清除应用存储。

## 4. 搜索词与网络信息

输入城市名后，应用经短暂防抖请求城市搜索服务，发送搜索词以取得名称、坐标和行政区信息。搜索框内容不作为搜索历史单独持久化；添加的结果会作为城市保存。

应用声明 `INTERNET` 权限。网络服务可接收到请求固有的 IP 地址、请求时间、客户端协议等信息；本应用不附带广告标识、通讯录、照片、账号或设备唯一标识。

## 5. 第三方服务与共享

当前网络服务如下：

- `api.open-meteo.com`：接收城市经纬度及预报参数，返回实况、逐时、逐日和太阳事件。中国附近部分坐标会额外请求 CMA GRAPES 模型，仍由该域名提供。
- `air-quality-api.open-meteo.com`：接收城市经纬度与空气质量查询参数，返回 PM2.5 等数据。
- `geocoding-api.open-meteo.com`：接收城市搜索词和搜索参数，返回候选地点。
- Android 系统位置与 Geocoder 服务：根据用户授权和设备系统的实现处理位置及地名解析。

Open-Meteo 按其[服务条款与隐私政策](https://open-meteo.com/en/terms)处理接收到的数据。网络请求可能由境外基础设施处理，具体以服务方的政策及部署为准。本项目不出售或出租个人数据，不向自建服务器上传城市、位置或使用记录。

应用依赖的界面、存储、网络和 Markdown 组件见“关于 → 数据来源与开源组件”，未接入独立的广告或统计服务。

## 6. 传感器与调试日志

首页可在本机读取设备方向传感器以绘制倾斜视差；读数不持久化、不上传，无传感器时可使用触摸模拟。

Debug 安装包启用 HTTP BASIC 日志，可能在设备调试日志中包含请求 URL（包括坐标或搜索词）、状态码和耗时；不会把这些日志自动发送给维护者。Release 不启用该网络日志。提交问题前请检查并移除日志中的敏感信息。

## 7. 保留、删除与系统备份

城市与最近一次天气会在本机保留，直到被后续数据替换或用户删除：

- 城市管理页长按或点击编辑，选择手动城市并确认删除，会移除城市条目、内存报告和磁盘缓存；仍在进行的请求不能重新写回已删除城市的天气。
- 定位城市当前不可单独删除。撤销定位权限不会清除已保存坐标。
- Android“应用信息 → 存储 → 清除存储”或卸载应用会删除本机私有副本；应用没有独立的账号注销或云端删除入口。
- 应用启用了 Android 备份能力。设备的自动备份或迁移可能包含城市和缓存，并在重装或换机时恢复。已有系统备份的删除、保留与恢复由设备或账号的备份设置管理，清除本机数据不等于删除已有备份。

应用没有独立的搜索历史、定位轨迹或服务器使用档案可供导出；维护者不能访问或代为删除用户的本机与系统备份数据。

## 8. 本地文档与外部网页

阅读包内文档不联网。用户主动点击 `http` / `https` 链接时，应用将目标地址交给系统浏览器，不使用 WebView，也不将城市、坐标或天气缓存附加到该链接。

浏览器与目标网站可能按自身政策处理 IP、Cookie、登录状态和访问日志。访问项目 Issues 或第三方政策时请自行决定是否提交信息。

## 9. 安全与用户选择

天气和搜索请求使用 HTTPS，本机存储受 Android 应用沙箱保护；应用未提供单独的数据库密码或自建加密云备份。请妥善管理设备解锁、调试权限和系统备份账号。

可以拒绝或撤销定位权限、手动选城、删除手动城市、停止使用或清除应用存储。网络关闭后可阅读已有缓存与本地文档，无法获取新的搜索结果和天气。

## 10. 未成年人和政策变更

应用不针对未成年人另行建立档案或提供广告画像。未成年人应在监护人指导下管理位置权限与公开反馈，避免公开精确位置或身份信息。

权限、服务方或数据处理变化时，会更新政策日期并在版本日志中说明。包内政策对应当前安装版本，仓库可能包含更新版本。

## 11. 联系

隐私问题通过[项目 Issues](https://github.com/SiXuManYan/hydrogen-weather-animation/issues)联系维护者。该平台的提交默认公开，请只提供排查所需信息，避免附带位置、身份或敏感日志。
