# 氢天气隐私政策

更新日期：2026 年 11 月 6 日。

## 1. 我们处理什么

氢天气没有账号、广告、行为统计、崩溃上报或自建服务器，不出售或出租个人数据。

- **城市与天气**：在本机保存城市名称、坐标、定位标记、顺序，以及最近一次天气和更新时间，用于城市切换和离线查看。
- **城市搜索**：把输入的城市名发送给搜索服务，不单独保存搜索历史；添加的城市会保存在本机。
- **设备姿态**：仅在本机用于倾斜动画，不持久化、不上传。

## 2. 定位由你选择

精确或大致位置权限均由系统询问，你可以拒绝或随时撤销，之后仍可手动添加城市。

获得授权后，应用读取系统最近位置或请求一次定位，用于确定城市、查询天气，并交给系统地名服务解析城市名。定位在成功、超时或取消后停止；不申请后台定位，不记录行踪。系统位置和地名服务可能联网，处理规则由设备提供方决定。

撤销权限不会清除已保存的定位城市或阻止按保存坐标查询天气；如需清除，请在系统设置中清除应用存储。定位成功率和位置更新限制见“使用帮助”。

## 3. 数据会发给谁

天气和搜索请求直接发送到 Open-Meteo，不经过项目服务器：

- `api.open-meteo.com`：接收城市坐标和预报参数，提供天气与日出日落。
- `air-quality-api.open-meteo.com`：接收城市坐标，提供 PM2.5 等数据。
- `geocoding-api.open-meteo.com`：接收搜索词，提供城市结果。

服务方可收到请求自带的 IP、时间等网络信息，应用不会附加广告标识、设备唯一标识、通讯录或照片。请求使用 HTTPS，可能由境外设施处理，详情见 [Open-Meteo 条款与隐私说明](https://open-meteo.com/en/terms)。

## 4. 保留与删除

- 城市和最近一次天气保留在应用私有存储中，直到更新或删除。
- 城市管理中删除手动城市，会同时删除其本机天气缓存；定位城市当前不可单独删除。
- 系统“应用信息 → 存储 → 清除存储”或卸载，会删除本机私有副本。
- Android 系统备份或换机迁移可能恢复城市和缓存。已有备份由设备或账号设置管理，清除本机数据不等于删除系统备份。

作者无法访问或代为删除你的本机数据和系统备份。应用没有云端账号或独立的使用档案可导出。

## 5. 文档、网页与日志

协议、隐私、帮助、更新日志和组件说明可离线阅读。点击网页链接时先显示提示，确认后使用浏览器标签页，不支持时使用系统浏览器；不会附加城市、坐标或天气缓存，也不使用 WebView。

浏览器和网站可能使用已有登录状态、Cookie，并按自身政策处理 IP 和访问记录。复制抖音号只在主动点击时写入剪贴板，应用不读取剪贴板内容。

调试安装包的本机 HTTP 日志仅记录请求方法、主机、状态码、耗时或错误类别，不记录坐标、搜索词、请求路径、Header 或正文。正式安装包不启用此日志；两者均不会自动向作者发送日志。分享反馈前请移除其他可能包含的敏感内容。

## 6. 你的选择与联系

你可以撤销定位、手动选城、删除手动城市、清除存储或停止使用。断网后仍可阅读已有缓存和本地文档。请妥善管理设备、调试权限和系统备份账号；未成年人应在监护人指导下管理位置权限与公开反馈。

数据处理或服务方变化时会更新本政策日期和版本日志，包内政策对应当前安装版本。组件列表见“数据来源与开源组件”。

隐私问题可通过[项目 Issues](https://github.com/SiXuManYan/hydrogen-weather-animation/issues)联系作者。反馈默认公开，请勿附带精确位置或身份信息。
